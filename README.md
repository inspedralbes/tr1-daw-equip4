**Pixel Plaza – Institut virtual multijugador**

## 📝 Descripció

Pixel Plaza és una aplicació web multijugador que recrea un institut virtual en dues dimensions.

Els usuaris poden accedir a un espai compartit, personalitzar el seu avatar, moure's pel mapa de l'institut i interactuar amb altres participants en temps real.

L'aplicació incorporarà videotrucades amb àudio i vídeo mitjançant WebRTC i Simple-Peer, així com un xat privat entre usuaris d'una mateixa sala.

El projecte es desenvolupa amb Vue 3, Phaser 3, Pinia, Node.js i Socket.IO, i es preveu desplegar mitjançant Docker i Docker Compose.

### Funcionalitats principals

- Identificació mitjançant nom i avatar.
- Lobby amb visualització de sales i usuaris connectats.
- Creació i unió a sales.
- Mapa virtual 2D de l'institut.
- Moviment i interacció amb avatars.
- Videotrucades individuals i grupals.
- Controls de micròfon i càmera.
- Xat privat entre usuaris de la mateixa sala.
- Eliminació dels missatges privats quan un usuari abandona la sala.
